## Artifact and ROM hygiene

- The JP ROM input is local dev input only. Do not commit or package ROM files.
- Generated recompilation outputs such as `RecompiledFuncs/`, `RecompiledPatches/`, patch binaries, APKs, CMake/Gradle build outputs, and caches should stay ignored or be cleaned before commit unless explicitly approved.
- If a dev-full APK ever packages ROM-derived generated assets, gate it clearly as local-only and verify APK contents before sharing.

## Recompilation input generation

- Host `N64Recomp` and `RSPRecomp` binaries can be copied into the repo root; they are ignored/local-only.
- Run `tools/generate_recomp_inputs.sh` after placing the required local ROM/ELF inputs in the repo root. CT1's script also builds and recompiles `patches/patches.elf`; use host LLVM `clang`/`ld.lld`/`llvm-objcopy`, not Android NDK clang, for the MIPS patch build.
- The script intentionally fails fast if required local-only inputs are missing.
